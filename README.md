# SaadA_CS457 - Tic-Tac-Toe

Tic-Tac-Toe is a 2 player game that is played over the network and is built for CS457.

## Game Rules
- **Players:** The first player to connect is **X** and moves first; the next move is **O** and so fourth.
- **Turns:** Players alternate entering a cell number (1-9). Invalid or occupied cells are rejected and the same player tries again.
- **Win:** Three marks in a row, horizontally, vertically, or diagonally.
- **Draw:** All 9 cells are filled with no winner.
